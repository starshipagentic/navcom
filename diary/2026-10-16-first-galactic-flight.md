# First galactic flight, with evidence underneath

We now have one cached geography consumed by the CLI and browser. The owner can
fly from galaxy to systems, products, experiments and districts; Starship's
existing artwork and fleet snapshot have real places. Search does not rearrange
the map, and returning restores the viewpoint and query.

The tools perform intake. On a fresh isolated browser fixture, opening the bridge
started discovery and Starforge harvest, showed progress, and produced a Polaris
system with separate Aurora, Radar and Compass destinations. Reload reused the
publication. Source discovery currently starts with bounded metadata/documents;
existing broader harvested code scopes stay registered. This is not a claim of
complete source coverage.

The Navigator uses the same service in `atlas navigate` and the web form. Typed or
transcribed requests execute a procedural read-only route through place metadata,
native Starforge concept/text results and indexed conversation search. A unique
destination resolves; duplicate names return choices. Syra actually has a system,
two project records and a recorded ship with that name. We do not choose for the
captain. No LLM is needed, and no model was downloaded.

Testing found and fixed a twelve-source search cutoff, missing projects in fresh
indexes, unreadable mobile labels, history replay of navigation commands, a
Library-switch timing problem, and a harvest pipe deadlock. Source search now
batches against one pinned harvest generation; repeated queries reuse caches.
The real 15-source/15-conversation test finds the last source and still excludes
files and conversations outside a selected scope.

Verification at this checkpoint: 230 NavCom pytest tests, 130 BDD scenarios,
native Starforge CLI scope/replay checks and real browser flight/search/return
journeys. A local wheel/source archive builds and the wheel is installed in the existing
pipx environment. This is a local preview, not a
published release. The preview contains full project metadata but only a bounded
subset of conversation turns; it cannot prove full-archive search completeness.

Not decided or not finished: historical product reconstruction, trustworthy living
star inventory, district naming and full source coverage, current ship boarding,
and actual microphone speech on this browser. Local voice correctly falls back
when no speech pack exists. Installed Starship inspection/recovery contracts and
Starforge history functions are being tested directly before new adapters are
wired. These gaps keep the full galactic goal active.
