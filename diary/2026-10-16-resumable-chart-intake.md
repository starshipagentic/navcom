# October 16 — The tools keep the chart moving

The bridge already lets the captain fly, but its source coverage still came from
an early, narrow lab set. Refresh began again at the first page and could spend
its whole time revisiting broad folders. The decision was to fix that shared CLI
path before adding more visual layers.

NavCom now pins its own indexed project inventory, groups conversation folders by
native Git working-tree root, and schedules existing Starforge harvest in bounded
workers. Progress is atomic and resumable. Each selected source publishes without
requiring other original source disks to be online. Pausing kills the worker group,
keeps complete snapshots, and retains the current job. A publication that beats
cancellation still leaves a saved obligation to rebuild geography.

Unversioned container folders keep their own context. Their descendant repositories,
indexed projects and product manifests become traversal boundaries. Explicit
registered scopes remain authoritative. No one copied a catalog or assigned client
ownership by hand. Native Git ignore checks now share one process per repository.

The browser uses this same service: visible progress, Pause, continuation, and a
ten-minute rest after completed automatic sweeps. Reopening reconnects to a running
refresh. Finishing a refresh cannot erase a draft question. A browser pass has a
two-minute budget; remaining work stays visible and resumes on Continue or the
next opening. The CLI reports the exact continuation command.

The chart also reconciles exact independently indexed LAB/app roots with their
existing experiment/product destination. Parent folders' own conversations join
their existing system. Conflicting declarations and cycles stay explicit; they do
not become guessed ownership. Native lineage remains a proposed relationship,
not permission to merge product identities.

Natural questions preserve the full input for Starforge concept search and use
Starforge's existing term extraction for the broader code/document path. Literal
quotes, paths and URLs retain literal behavior. Results name their saved product
path memberships and distinguish matching evidence from unknown coverage. This
returns evidence, not a fabricated explanation. Back/reload shares the same query
plan; a request reads one chart publication throughout.

## Evidence and remaining limits

- Native CLI proof: automatic discovery → harvest → chart → separate unfamiliar
  applications → both search paths → cached repeat and restored natural question.
- Live inventory: 338 indexed project folders group into 294 source jobs. Earlier
  bounded passes published usable geography after eight visited project folders;
  broad coverage is still incomplete and is reported as such.
- Container dry run: `~/clients` fell from 511 overlapping files to three own-context
  files, with delegated boundaries recorded. Observatory native ignore checks fell
  from 177 processes to one; remaining directory limits stay visible.
- Spatial live audit reconciled six duplicate destinations without changing the
  retained moon IDs/positions. Astronomus experiments now carry their conversations.

No new ownership classifier, lineage-based automatic merging, physical-copy
chronology, or new model was introduced. Real microphone capture, expert response,
and captain takeover still require their separate end-to-end proof. The complete
navigation goal remains active.

Final gate: 468 pytest cases and all 130 BDD scenarios / 699 steps passed. The
installed wheel matches all 33 runtime files. Browser proof includes refresh
reconnection, a preserved unfinished question during Pause, Syra's separate product
planets, Cognito source/conversation evidence, cached source reading, and
Escape/Back/Forward with the same restored native query terms. The bridge remains
open; its automatic grouped sweep is still bounded and incomplete.
