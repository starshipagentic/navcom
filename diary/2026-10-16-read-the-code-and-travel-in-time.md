# Read the code and travel in time

The previous checkpoint put the full archive on the bridge and verified real
EXP32/matrix navigation, History, ship inspection and mobile Fly controls.
The full galactic goal remains active.

This pass follows three concrete paths through the existing tools:

1. Discover maintained-expertise candidates through native Hermes inventory,
   installed Starship/Starforge detectors and standard Compose/OCI metadata.
   Keep candidate evidence separate from an explicit provider status observation.
2. Open the exact harvested code/document behind a search result, with line
   numbers, snapshot provenance and bounded paging. Do not silently substitute
   changed files in the live worktree.
3. Reconstruct several product addresses at a selected UTC date from pinned Git
   HEADs and committed trees. Use existing historical Starforge harvest/search;
   retain every current address, making missing or unvisited history explicit.

Star discovery found the real Observatory without a project-name rule. Its source
was brought in through NavCom's own discover/harvest command. An initial real
refresh exposed a batching bug: broad chat working directories such as the home
folder poisoned unrelated roots under the provider provenance guard. Those

observed that container running with its provider binding; expert/model readiness
remains unverified.

An initial real Syra time request pinned 13 repositories for 42 current product
addresses and reconstructed the first two trees before returning a continuation
cursor. This is evidence of a working path, not a claim that historical ownership
or every old product has been recovered. Current labels are address clues only;
historical content and names must come from the selected commit.

Decided: keep one shared CLI/API service for each operation, expose cache and
coverage provenance, and preserve chart identity across exploration. No agents,
models, Docker containers or gateways start during discovery/inspection.

UI journeys now cover source paging, Back, Escape and mobile overflow, star
inspection with an explicit process observation, and old/new dated charts with
slider/Back preserving positions and committed code. The real Syra browser
continued from four to five of thirteen pinned repository jobs. CLI continuation

Remaining and unknown places stay visible.

directories were each spawning Git just to check for LFS pointers. Native

object-hash checks; skipped directories stay skipped. The same 1,779-file Syra
revision plus native harvest completes in 9.507 seconds. Continuing visits all
thirteen pinned repositories and reconstructs thirteen of forty-two addresses;
one separate file/byte-budget exclusion and unavailable old paths remain honest
gaps. A 100-object comparison was byte-identical: 2.4415 seconds serial versus
0.0164 seconds with Git's batch reader.
